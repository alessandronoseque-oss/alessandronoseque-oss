### 🚀 Proyecto destacado

**[Olist E-commerce Analysis](https://github.com/alessandronoseque-oss/olist-ecommerce-analysis)**
Análisis end-to-end (Python, SQL Server, Power BI) sobre ~100,000 pedidos de un marketplace brasileño, para identificar qué factores logísticos explican la insatisfacción del cliente.

- 🔍 Diagnóstico y limpieza de datos con `pandas`
- 🗄️ Modelado en esquema estrella (SQL Server) + 5 KPIs de negocio
- 📊 Dashboard ejecutivo en Power BI con medidas DAX
- 💡 Hallazgo clave: retrasos de 15+ días reducen la satisfacción del cliente en **60%**
